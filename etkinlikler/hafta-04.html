İçe aktarma deneyi

İlerleme
0 / 3
  1. Varsayılan ayarlar

    karakter_16.png'yi hiçbir ayarı değiştirmeden sahneye koyun, yanına 2. haftadaki kareyi koyun. Game penceresinde yakınlaştırıp ekran görüntüsü alın.

    Kontrol: Karakter küçük ve bulanık.
  2. Düzeltin

    Görseli seçin:

    Pixels Per Unit16Filter ModePoint (no filter)CompressionNone

    Apply, yeni ekran görüntüsü.

    Kontrol: Karakter keskin ve kareyle aynı boyda.
  3. Pixel Perfect Camera

    Main Camera'ya ekleyin, Assets Pixels Per Unit 16. Game penceresinin boyutunu değiştirip deneyin.

İlerleme
0 / 3
  1. Normal haritasını işaretleyin

    Üç görseli _Proje/Textures'a alın. tugla_normal: Texture Type Normal map, Apply.

  2. Üç küp

    x = −2, 0, 2 konumlarına üç küp koyun.

  3. Üç materyal

    Hepsinin Base Map'i tuğla dokusu:

    Tugla_KuruSmoothness 0,1Tugla_IslakSmoothness 0,85Tugla_NormalSmoothness 0,2 + Normal Map

    Sırayla küplere uygulayın.

    Kontrol: Aynı doku üç farklı malzeme gibi görünüyor.

Daha ileri

20 dk
İlerleme
0 / 2
  1. Sprite sheet

    karakter_yuruyus.png:

    Sprite ModeMultiplePixels Per Unit32Filter / CompressionPoint / None

    Open Sprite Editor›Slice›Grid By Cell Size 32 × 32›Slice›Apply

    Kontrol: 8 ayrı kare var; 11. haftada animasyon olacaklar.
  2. Sprite Atlas

    Sprites›Create›2D›Sprite Atlas; Objects for Packing'e Sprites klasörünü ekleyin, Pack Preview.

İlerleme
0 / 3
  1. Işığı çevirin

    Directional Light'ın Rotation Y'sini yavaşça değiştirin, üç küpü karşılaştırın.

  2. Tel kafes

    Scene penceresinde Shading Mode → Wireframe. Üçüncü küpe bakın.

    Kontrol: Pürüzlü görünen küp hâlâ düz, 12 üçgenlik bir küp.
  3. Tahta ve tiling

    Tahta materyalini bir düzleme uygulayın; Tiling 4 × 4 yapın.
