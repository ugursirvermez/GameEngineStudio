02

Adımlar

Kendi yolunuzu seçin; seçiminiz bütün etkinlik sayfalarında hatırlanır.
İlerleme
0 / 5
  1. Varsayılan ayarlarla içe aktarın

    karakter_16.png'yi _Proje/Sprites'a sürükleyin ve hiçbir ayarı değiştirmeden sahneye koyun. Yanına 2. haftadaki kare sprite'ı koyun. Game penceresinde yakınlaştırıp bir ekran görüntüsü alın.

    Kontrol: Karakter küçük ve bulanık görünüyor.
  2. Ayarları düzeltin

    Görseli seçin: Pixels Per Unit = 16, Filter Mode = Point (no filter), Compression = None. Apply. Yeni bir ekran görüntüsü alın.

    Kontrol: Karakter keskin ve kare sprite ile aynı boyda (1 × 1 birim).
  3. Pixel Perfect Camera

    Main Camera'ya Add Component → Pixel Perfect Camera. Assets Pixels Per Unit = 16. Game penceresinin boyutunu değiştirip piksellerin eşit kalıp kalmadığına bakın.

  4. Sprite sheet dilimleyin

    karakter_yuruyus.png'yi içe aktarın; Sprite Mode = Multiple, PPU 32, Point, None. Open Sprite Editor → Slice → Type: Grid By Cell Size → 32 × 32 → Slice → Apply.

    Kontrol: Görselin yanındaki okla açınca 8 ayrı kare görünüyor. 11. haftada bunlarla animasyon kuracaksınız.
  5. Sprite Atlas

    _Proje/Sprites → Create → 2D → Sprite Atlas. Atlasın Objects for Packing listesine Sprites klasörünü ekleyin, Pack Preview'e basın.

İlerleme
0 / 7
  1. Dokuları içe aktarın

    Üç görseli _Proje/Textures'a sürükleyin. tugla_normal'ı seçin ve Texture Type'ı Normal map yapın, Apply.

    Kontrol: Normal haritasının önizlemesi mavi-mor görünüyor.
  2. Üç küp

    Sahneye yan yana üç küp koyun (x = −2, 0, 2).

  3. Kuru tuğla

    _Proje/Materials → Create → Material, adı Tugla_Kuru. Base Map'e tuğla dokusu, Smoothness 0,1. Birinci küpe uygulayın.

  4. Islak tuğla

    Tugla_Islak: aynı doku, Smoothness 0,85. İkinci küpe uygulayın.

  5. Normal haritalı tuğla

    Tugla_Normal: aynı doku, Smoothness 0,2, Normal Map alanına tugla_normal. Üçüncü küpe uygulayın.

  6. Işığı çevirin

    Directional Light'ı seçip Rotation Y değerini yavaşça değiştirin. Üç küpü karşılaştırın. Sonra Scene penceresinin üst menüsünden Shading Mode → Wireframe'e geçip üçüncü küpün geometrisine bakın.

    Kontrol: Üçüncü küp pürüzlü görünüyor ama tel kafeste hâlâ 12 üçgenlik düz bir küp.
  7. Tahta

    Tahta materyalini kurun ve bir düzleme (Plane) uygulayın. Tiling değerini 4 × 4 yapın ve farkına bakın.

Teslim ve tamamlanma ölçütleri

  • 2B: önce/sonra ekran görüntüleri; sonra görüntüsünde karakter keskin ve 1 × 1 birim. Sprite sheet 8 kareye dilimlenmiş.

06

Final projesine taşı

Final projeniz için bütün görselleri aynı PPU ile (2B) ya da aynı materyal düzeniyle (3B) hazırlayın. Tasarım belgesine hangi görselleri nereden bulacağınızı ya da nasıl çizeceğinizi not edin. Telifsiz görsel kaynakları: Kenney (kenney.nl), OpenGameArt; lisans koşullarını raporunuzda belirtin.
