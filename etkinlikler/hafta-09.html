İlerleme
0 / 5
  1. Kartı hazırlayın

    kart.png: PPU 32, Point, None. Sahneye koyun; adı Secenek_A. Add Component → Box Collider 2D, Is Trigger işaretli.

  2. Yazı

    Karta sağ tık → 3D Object → Text - TextMeshPro (sahne içi yazı; arayüz yazısı değil). İlk kullanımda çıkan pencerede Import TMP Essentials. Yazıyı seçenek metni yapın, boyutunu karta uydurun. TextMeshPro bileşeninin Extra Settings bölümünde Order in Layer'ı karttan büyük yapın.

    Kontrol: Kartın üzerinde seçenek yazısı okunuyor.
  3. Script

    Secenek2D.cs'yi karta ekleyin. Doğru seçenekte Dogru Mu'yu işaretleyin.

  4. Üç seçenek

    Kartı prefab'a çevirin, iki kopya daha koyun ve yazılarını değiştirin (override). Yalnızca birinin Dogru Mu'su işaretli olsun. Kartları karakterin yürüyerek ulaşabileceği yerlere yerleştirin.

  5. Oyuncu

    7. haftadaki karakterin Tag'inin Player olduğunu kontrol edin. ▶ ile kartlara yürüyün.

    Kontrol: Doğru kart kayboluyor; yanlış karta değince karakter geri itiliyor ve Console'da ileti çıkıyor.
Secenek2D.cs
using UnityEngine;

// 2B soru seçeneği. Seçeneğin Collider2D'sinde Is Trigger açık olmalı;
// oyuncu karakterinin Tag'i "Player" olmalı.
public class Secenek2D : MonoBehaviour
{
    [SerializeField] private bool dogruMu;
    [SerializeField] private float geriItmeMesafesi = 0.8f;   // yanlışta oyuncu ne kadar geri itilsin

    private void OnTriggerEnter2D(Collider2D diger)
    {
        if (!diger.CompareTag("Player")) return;

        if (dogruMu)
        {
            Debug.Log($"Doğru: {name}");
            gameObject.SetActive(false);                       // seçenek toplanır
        }
        else
        {
            Debug.Log($"Yanlış: {name}. Tekrar dene.");
            // Oyuncuyu seçenekten uzaklaştır; seçenek yerinde kalır, yeniden denenebilir.
            float yon = Mathf.Sign(diger.transform.position.x - transform.position.x);
            diger.transform.position += new Vector3(yon * geriItmeMesafesi, 0f, 0f);
            Rigidbody2D rb = diger.attachedRigidbody;
            if (rb != null) rb.linearVelocity = new Vector2(rb.linearVelocity.x, 5f);
        }
    }
}
İlerleme
0 / 5
  1. Seçenek nesneleri

    Üç küp koyun (Secenek_A/B/C), aralarında boşluk bırakın. Her birine ayrı bir materyal verin (URP Lit, açık gri) ki renkleri ayrı ayrı değişebilsin.

  2. Yazı

    Her küpün önüne 3D Object → Text - TextMeshPro ile seçenek yazısını koyun (TMP Essentials'ı içe aktarın).

  3. Script'ler

    Her küpe Secenek3D.cs ekleyin, doğru olanda Dogru Mu'yu işaretleyin. Main Camera'ya TiklaSec.cs ekleyin.

  4. Deneyin

    ▶ ile küplere tıklayın.

    Kontrol: Doğru küp yeşile dönüyor ve öyle kalıyor; yanlış küp kısa süre kırmızı olup eski rengine dönüyor.
  5. Katman süzgeci

    Secilebilir adlı bir katman oluşturup yalnızca üç küpe verin. TiklaSec'in Secilebilir alanında yalnızca bu katmanı seçin. Önüne başka bir nesne koyup farkı deneyin.

Secenek3D.cs
using UnityEngine;

// 3B soru seçeneği. TiklaSec script'i fareyle tıklanan seçeneğin Sec() metodunu çağırır.
public class Secenek3D : MonoBehaviour
{
    [SerializeField] private bool dogruMu;
    [SerializeField] private Color dogruRengi = new Color(0.2f, 0.7f, 0.35f);
    [SerializeField] private Color yanlisRengi = new Color(0.85f, 0.25f, 0.2f);

    private Renderer rend;
    private Color ilkRenk;

    void Awake()
    {
        rend = GetComponent<Renderer>();
        ilkRenk = rend.material.GetColor("_BaseColor");   // URP Lit materyalinde temel renk
    }

    public void Sec()
    {
        if (dogruMu)
        {
            Debug.Log($"Doğru: {name}");
            rend.material.SetColor("_BaseColor", dogruRengi);
        }
        else
        {
            Debug.Log($"Yanlış: {name}. Tekrar dene.");
            rend.material.SetColor("_BaseColor", yanlisRengi);
            Invoke(nameof(RengiSifirla), 0.6f);
        }
    }

    private void RengiSifirla()
    {
        rend.material.SetColor("_BaseColor", ilkRenk);
    }
}
TiklaSec.cs
using UnityEngine;
using UnityEngine.InputSystem;

// Kameradan, farenin tıklandığı noktaya ışın gönderir.
// Işın bir Secenek3D'ye çarparsa onun Sec() metodunu çağırır.
public class TiklaSec : MonoBehaviour
{
    [SerializeField] private LayerMask secilebilir = ~0;   // varsayılan: bütün katmanlar
    [SerializeField] private float menzil = 100f;

    void Update()
    {
        if (Mouse.current == null || !Mouse.current.leftButton.wasPressedThisFrame) return;

        Ray isin = Camera.main.ScreenPointToRay(Mouse.current.position.ReadValue());
        if (Physics.Raycast(isin, out RaycastHit carpma, menzil, secilebilir))
        {
            Secenek3D secenek = carpma.collider.GetComponent<Secenek3D>();
            if (secenek != null) secenek.Sec();
        }
    }
}

04

Teslim ve tamamlanma ölçütleri

  • Üç seçenek var, yalnızca biri doğru; seçenekler bir prefab'dan (2B) ya da aynı script'le (3B) kurulmuş.
  • Doğru seçenek toplanıyor ya da işaretleniyor; yanlış seçenek yerinde kalıyor ve yeniden denenebiliyor.
  • Console'da doğru/yanlış iletileri görünüyor.
  • Tasarım soruları yanıtlanmış.
