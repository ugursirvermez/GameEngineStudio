02

Karakteri hazırlayın

Kendi yolunuzu seçin; seçiminiz bütün etkinlik sayfalarında hatırlanır.
İlerleme
0 / 5
  1. Karakter nesnesi

    5. haftadaki mekânı açın. karakter_16 sprite'ını sahneye sürükleyin; adı Oyuncu, Tag = Player.

  2. Fizik bileşenleri

    Add Component → Rigidbody2D; Constraints → Freeze Rotation Z işaretli (karakter devrilmesin). Add Component → Capsule Collider 2D; boyutunu karaktere uydurun.

    Kontrol: ▶ ile karakter düşüp zemine konuyor.
  3. Ayak noktası

    Oyuncu'ya sağ tık → Create Empty; adı Ayak, Position (0, −0,5, 0).

  4. Zemin katmanı

    Herhangi bir nesnenin Inspector'ında Layer → Add Layer… ile Ground katmanını oluşturun. Zemin Tilemap'inin Layer'ını Ground yapın.

  5. Script'i ekleyin

    Hareket2D.cs'yi Oyuncu'ya ekleyin. Ayak alanına Ayak nesnesini sürükleyin, Zemin Katmani'nda Ground'u seçin.

İlerleme
0 / 5
  1. Karakter nesnesi

    5. haftadaki blok taslağı açın. Olcek kapsülünü karakter olarak kullanın: adı Oyuncu, Tag = Player. Kapsülün Capsule Collider bileşenini kaldırın.

  2. CharacterController

    Add Component → Character Controller. Height 2, Radius 0,5, Center (0, 0, 0).

  3. Yön göstergesi

    Kapsülün önünü görebilmek için çocuk olarak küçük bir küp ekleyin (Burun, Position (0, 0.5, 0.5), Scale 0,3).

  4. Kamera

    Main Camera'yı Oyuncu'nun çocuğu yapın: Position (0, 1.5, −4), Rotation X 12.

  5. Script'i ekleyin

    Hareket3D.cs'yi Oyuncu'ya ekleyin. Bir de eğim deneyi için 20° eğik bir rampa (döndürülmüş küp) koyun.

03

Görevleri doldurun

Script'i açın (çift tıklayın). İçinde // GÖREV 1'den // GÖREV 5'e kadar yorumlar var; her birinin altına istenen satırı yazın. İpuçları yorumların içinde. Her görevden sonra kaydedip Unity'ye dönün ve Console'da kırmızı hata olmadığından emin olun.

Kendi yolunuzu seçin; seçiminiz bütün etkinlik sayfalarında hatırlanır.
İlerleme
0 / 5
  1. GÖREV 1 · Eylemleri bulun

    Move ve Jump eylemlerini InputSystem.actions.FindAction ile bulup alanlara atayın.

  2. GÖREV 2 · Yatay girdi

    Update'te Move eyleminin x değerini okuyun.

  3. GÖREV 3 · Zıplama isteği

    Jump bu karede basıldıysa isteği kaydedin. Neden burada zıplatmıyoruz da yalnızca kaydediyoruz?

  4. GÖREV 4 · Yatay hız

    FixedUpdate'te hızı ayarlayın; dikey hızı koruyun.

    Kontrol: Karakter sağa-sola yürüyor ve düşmeye devam ediyor.
  5. GÖREV 5 · Zıplama

    Ayak noktasında zemin varsa ve istek varsa zıplatın.

    Kontrol: Karakter yalnızca yerdeyken zıplıyor; havadayken basılan zıplama işe yaramıyor.
Çözümü göster
Hareket2D.cs (çözüm)
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody2D))]
public class Hareket2D : MonoBehaviour
{
    [SerializeField] private float hiz = 6f;
    [SerializeField] private float ziplamaHizi = 12f;
    [SerializeField] private Transform ayak;
    [SerializeField] private LayerMask zeminKatmani;

    private Rigidbody2D rb;
    private InputAction hareket;
    private InputAction zipla;
    private float yatay;
    private bool ziplamaIstendi;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        hareket = InputSystem.actions.FindAction("Move");          // GÖREV 1
        zipla = InputSystem.actions.FindAction("Jump");
    }

    void Update()
    {
        yatay = hareket.ReadValue<Vector2>().x;                     // GÖREV 2
        if (zipla.WasPressedThisFrame()) ziplamaIstendi = true;     // GÖREV 3
    }

    void FixedUpdate()
    {
        rb.linearVelocity = new Vector2(yatay * hiz, rb.linearVelocity.y);   // GÖREV 4

        bool zeminde = Physics2D.OverlapCircle(ayak.position, 0.1f, zeminKatmani);   // GÖREV 5
        if (ziplamaIstendi && zeminde)
            rb.linearVelocity = new Vector2(rb.linearVelocity.x, ziplamaHizi);

        ziplamaIstendi = false;
    }
}
İlerleme
0 / 5
  1. GÖREV 1 · Eylemleri bulun

    Move ve Jump eylemlerini bulup alanlara atayın.

  2. GÖREV 2 · Girdi

    Move eyleminin iki boyutlu değerini okuyun.

  3. GÖREV 3 · Yön

    Karakterin baktığı yöne göre yön vektörünü hesaplayın; uzunluğu 1'i aşarsa normalleştirin.

  4. GÖREV 4 · Zemin ve zıplama

    cc.isGrounded ise dikey hızı −1 yapın, zıplama basıldıysa zıplama hızını verin.

  5. GÖREV 5 · Tek Move

    Yatay ve dikey hızı birleştirip karede tek cc.Move çağrısıyla uygulayın.

    Kontrol: Kapsül yürüyor, rampayı tırmanıyor, yerdeyken zıplıyor.

Hareket3D.cs (çözüm)
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(CharacterController))]
public class Hareket3D : MonoBehaviour
{
    [SerializeField] private float hiz = 5f;
    [SerializeField] private float ziplamaHizi = 6f;
    [SerializeField] private float yercekimi = -20f;

    private CharacterController cc;
    private InputAction hareket;
    private InputAction zipla;
    private float dikeyHiz;

    void Awake()
    {
        cc = GetComponent<CharacterController>();
        hareket = InputSystem.actions.FindAction("Move");          // GÖREV 1
        zipla = InputSystem.actions.FindAction("Jump");
    }

    void Update()
    {
        Vector2 girdi = hareket.ReadValue<Vector2>();               // GÖREV 2

        Vector3 yon = transform.right * girdi.x + transform.forward * girdi.y;   // GÖREV 3
        if (yon.sqrMagnitude > 1f) yon.Normalize();

        if (cc.isGrounded)                                          // GÖREV 4
        {
            dikeyHiz = -1f;
            if (zipla.WasPressedThisFrame()) dikeyHiz = ziplamaHizi;
        }

        dikeyHiz += yercekimi * Time.deltaTime;

        cc.Move((yon * hiz + Vector3.up * dikeyHiz) * Time.deltaTime);         // GÖREV 5
    }
}
04

Kodunuzu sınayın

Çalışan bir kod yetmez; doğru çalıştığını sınayın. Boş bir nesneye FPSSinir.cs ekleyin ve aşağıdaki tabloyu doldurun.

Sınama tablosu
FPSSinir.cs
using UnityEngine;

// Kare hızını sınırlar. Hareket kodunun Time.deltaTime'a doğru bağlanıp
// bağlanmadığını sınamak için: 30 ve 120 değerlerinde karakter aynı hızda gitmeli.
public class FPSSinir : MonoBehaviour
{
    [SerializeField] private int hedefKareHizi = 30;

    void Start()
    {
        QualitySettings.vSyncCount = 0;              // dikey eşitleme açıkken sınır uygulanmaz
        Application.targetFrameRate = hedefKareHizi;
    }
}
05

Teslim ve tamamlanma ölçütleri

  • Beş görev de doldurulmuş, Console'da hata yok.
  • Karakter 5. haftadaki mekânda yürüyor ve yalnızca yerdeyken zıplıyor.
  • Hareket 30 ve 120 kare hızında yaklaşık aynı sürede aynı mesafeyi alıyor.
  • Sınama tablosu doldurulmuş.
Vize hazırlığı. Bu hafta vize kapsamının son haftası. Hareket kodunu bir kez de çözüme ve notlara bakmadan, boş bir script'e sıfırdan yazmayı deneyin. Deneme vize etkinliği bunun için.
