02

Adımlar

Kendi yolunuzu seçin; seçiminiz bütün etkinlik sayfalarında hatırlanır.
İlerleme
0 / 7
  1. Serileri dilimleyin

    İki görseli içe aktarın: Sprite Mode Multiple, PPU 32, Point, None. Sprite Editor → Grid By Cell Size 32 × 32 → Slice → Apply.

    Kontrol: Yürüme 8, bekleme 2 kareye ayrıldı.
  2. Karakterin görselini değiştirin

    7. haftadaki Oyuncu'nun Sprite Renderer'ında sprite'ı karakter_bekleme_0 yapın. Collider'ı yeni boya uydurun; Ayak nesnesini ayağın altına taşıyın.

  3. Klipler

    Window → Animation → Animation. Oyuncu seçiliyken Create; _Proje/Animations/Bekleme.anim. Bekleme'nin iki karesini zaman çizgisine sürükleyin. Klip menüsünden Create New Clip → Yurume.anim; sekiz yürüme karesini sürükleyin.

  4. Kare hızı

    Animation penceresinin sağ üst menüsünden Show Sample Rate. Yürüme için Samples 10, bekleme için 3.

    Kontrol: ▶ ile karakter olduğu yerde bekleme animasyonu oynatıyor.
  5. Animator

    Window → Animation → Animator. Parameters sekmesinde + → Float, adı Speed. Bekleme'den Yurume'ye sağ tık → Make Transition: Has Exit Time kapalı, Transition Duration 0, koşul Speed Greater 0.1. Ters yönde geçiş: koşul Speed Less 0.1, aynı ayarlar.

  6. Script

    KarakterAnimasyonu2D.cs'yi Oyuncu'ya ekleyin. ▶ ile yürüyün.

    Kontrol: Yürürken yürüme, dururken bekleme oynuyor; sola gidince karakter sola dönüyor.
  7. His ayarı

    Yürüme kare hızını 6, 10 ve 16 yapıp deneyin; karakterin yürüme hızıyla (Hareket2D'deki hiz) uyumlu olanı seçin. Ayakların kaymadığı değeri bulun.

KarakterAnimasyonu2D.cs
using UnityEngine;

// Rigidbody2D'nin yatay hızını Animator'daki "Speed" parametresine yazar
// ve karakteri gittiği yöne çevirir. Klip seçimini Animator Controller yapar.
[RequireComponent(typeof(Animator), typeof(SpriteRenderer), typeof(Rigidbody2D))]
public class KarakterAnimasyonu2D : MonoBehaviour
{
    private Animator animator;
    private SpriteRenderer spriteRenderer;
    private Rigidbody2D rb;

    void Awake()
    {
        animator = GetComponent<Animator>();
        spriteRenderer = GetComponent<SpriteRenderer>();
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        float yatayHiz = rb.linearVelocity.x;
        animator.SetFloat("Speed", Mathf.Abs(yatayHiz));

        if (Mathf.Abs(yatayHiz) > 0.01f)
            spriteRenderer.flipX = yatayHiz < 0f;          // görseller sağa bakacak biçimde çizildi
    }
}
İlerleme
0 / 6
  1. Karakteri indirin

    mixamo.com'da oturum açın. Characters sekmesinden bir karakter seçin (ör. X Bot). Download: Format FBX for Unity (.fbx), Pose T-pose.

  2. Animasyonları indirin

    Animations sekmesinde Idle, Walking ve Running arayın. Yürüme ve koşmada In Place'i işaretleyin (karakteri kod hareket ettirecek). Her birini FBX for Unity, Without Skin olarak indirin.

  3. İçe aktarın

    Dört dosyayı _Proje/Models'a sürükleyin. Karakter dosyasını seçin: Rig → Animation Type: Humanoid, Avatar Definition: Create From This Model, Apply. Animasyon dosyalarında: Humanoid, Copy From Other Avatar → karakterin avatarı. Animation sekmesinde Loop Time işaretli.

    Kontrol: Karakter dosyasının Rig sekmesinde Configure düğmesinin yanında onay işareti var.
  4. Modeli yerleştirin

    7. haftadaki Oyuncu kapsülünün Mesh Renderer'ını kapatın. Karakter modelini Oyuncu'nun çocuğu yapın; ayakları kapsülün altına gelecek biçimde Position Y'yi ayarlayın (−1).

  5. Blend Tree

    _Proje/Animations → Create → Animator Controller, modelin Animator'ına atayın. Animator penceresinde sağ tık → Create State → From New Blend Tree; çift tıklayın. Parametre Speed (Float), Blend Type 1D. Üç Motion Field: Idle, Walking, Running. Automate Thresholds'ı kapatıp eşikleri 0, 2 ve 5 yapın.

  6. Script

    KarakterAnimasyonu3D.cs'yi Oyuncu'ya ekleyin (Animator'ı kendisi bulur). ▶ ile yürüyün; Hareket3D'deki Hiz'ı 2 ve 5 yapıp farkı görün.

    Kontrol: Durunca bekleme, yavaşken yürüme, hızlıyken koşma oynuyor; geçişler yumuşak.
KarakterAnimasyonu3D.cs
using UnityEngine;

// CharacterController'ın yatay hızını Animator'daki "Speed" parametresine yazar.
// Blend Tree bu değere göre bekleme, yürüme ve koşma arasında geçiş yapar.
[RequireComponent(typeof(CharacterController))]
public class KarakterAnimasyonu3D : MonoBehaviour
{
    [SerializeField] private Animator animator;   // model çocuk nesnedeyse buraya sürükleyin

    private CharacterController cc;

    void Awake()
    {
        cc = GetComponent<CharacterController>();
        if (animator == null) animator = GetComponentInChildren<Animator>();
    }

    void Update()
    {
        Vector3 v = cc.velocity;
        float yatayHiz = new Vector3(v.x, 0f, v.z).magnitude;
        animator.SetFloat("Speed", yatayHiz, 0.1f, Time.deltaTime);   // 0,1 s yumuşatma
    }
}

Teslim ve tamamlanma ölçütleri

  • En az iki animasyon (bekleme ve yürüme) var ve harekete göre geçiş yapıyor.
  • Geçişler anında tepki veriyor (Has Exit Time kapalı).
  • Script klip seçmiyor, yalnızca Speed parametresini güncelliyor.
  • 2B: karakter yönüne göre çevriliyor. 3B: Blend Tree üç hareketi karıştırıyor.

Final projesine taşı

Animasyon, projeniz hareket, beden ya da süreç anlatıyorsa (eklem, büyüme, dönüşüm) doğrudan öğrenme malzemesidir; öyle değilse bir iki basit geri bildirim animasyonu (doğru yanıtta zıplama) yeter. Zamanınızı öğretime katkısı olan yere harcayın.
