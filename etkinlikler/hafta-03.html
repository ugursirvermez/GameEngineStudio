02

Eşyayı kurun

Kendi yolunuzu seçin; seçiminiz bütün etkinlik sayfalarında hatırlanır.
İlerleme
0 / 5
  1. Sprite'ı içe aktarın

    yildiz.png'yi seçin. Inspector'da Pixels Per Unit = 32, Filter Mode = Point (no filter), Compression = None. Apply.

    Kontrol: Sprite sahnede keskin ve 1 × 1 birim görünüyor.
  2. Boş nesneden başlayın

    GameObject → Create Empty. Adı Yildiz. Inspector'da yalnızca Transform olduğuna dikkat edin: nesne sahnede var ama görünmüyor.

  3. Görünür yapın

    Add Component → Sprite Renderer. Sprite alanına yildiz'ı sürükleyin.

  4. Temas sınırı ekleyin

    Add Component → Circle Collider 2D. Is Trigger'ı işaretleyin (9. haftada toplanabilir olacak).

    Kontrol: Scene penceresinde yıldızın çevresinde yeşil bir daire görünüyor.
  5. Döndürün

    Donme.cs'yi nesnenin Inspector'ına sürükleyin. Eksen alanı (0, 0, 1) kalsın. ▶ ile deneyin.

    Kontrol: Yıldız kendi çevresinde dönüyor.
İlerleme
0 / 5
  1. Boş nesneden başlayın

    GameObject → Create Empty. Adı Para. Inspector'da yalnızca Transform var.

  2. Şekil ve çizim bileşenleri

    Add Component → Mesh Filter; Mesh alanından Cylinder'ı seçin. Ardından Add Component → Mesh Renderer. İki bileşen eklenene kadar nesnenin görünmediğine dikkat edin. Scale'i (1, 0.08, 1), Rotation X'i 90 yapın.

  3. Materyal

    _Proje/Materials → Create → Material, adı Altin. Base Map rengi sarı, Metallic 1, Smoothness 0,7. Materyali paraya sürükleyin.

    Kontrol: Para parlak, metalik sarı görünüyor.
  4. Temas sınırı

    Add Component → Capsule Collider (ya da Sphere Collider), Is Trigger'ı işaretleyin.

  5. Döndürün

    Donme.cs'yi ekleyin. Eksen alanını (0, 1, 0) yapın. ▶ ile deneyin.

    Kontrol: Para dik ekseni çevresinde dönüyor.
Donme.cs
using UnityEngine;

// Nesneyi belirtilen eksen çevresinde döndürür.
// 2B'de eksen (0, 0, 1), 3B'de genellikle (0, 1, 0) seçilir.
public class Donme : MonoBehaviour
{
    [SerializeField] private float derecePerSaniye = 90f;
    [SerializeField] private Vector3 eksen = new Vector3(0f, 0f, 1f);

    void Update()
    {
        transform.Rotate(eksen * derecePerSaniye * Time.deltaTime);
    }
}
03

Prefab ve override

İlerleme
0 / 6
  1. Prefab'a çevirin

    Nesneyi Hierarchy'den Project penceresindeki _Proje/Prefabs klasörüne sürükleyin. Hierarchy'de adı maviye döner.

    Kontrol: Prefabs klasöründe mavi küp simgeli bir dosya var.
  2. Beş kopya

    Prefab'ı sahneye dört kez daha sürükleyin; kopyaları farklı yerlere koyun.

  3. Kalıbı değiştirin

    Project penceresinde prefab'a çift tıklayın (prefab düzenleme kipi açılır). Derece Per Saniye'yi 360 yapın, sol üstteki ‹ okuyla sahneye dönün.

    Kontrol: Beş kopyanın hepsi daha hızlı dönüyor.
  4. Override oluşturun

    Sahnede tek bir kopyayı seçin, onun hızını 30 yapın. Alanın kalın yazıyla işaretlendiğine dikkat edin. Şimdi kalıbın hızını tekrar değiştirin.

    Kontrol: Kalıp değişince dört kopya değişti, override'lı kopya değişmedi.
  5. Geri alın

    Override'lı kopyayı seçin; Inspector'ın üstündeki Overrides menüsünden Revert All.

  6. Otomatik üretim

    Boş bir nesne oluşturun (Uretici), Uretici.cs'yi ekleyin, Kalip alanına prefab'ı sürükleyin. ▶ ile deneyin.

    Kontrol: İki saniyede bir yeni kopya beliriyor, en fazla on tane.
Uretici.cs
using UnityEngine;

// Belirli aralıklarla bir prefab'dan yeni kopya üretir.
public class Uretici : MonoBehaviour
{
    [SerializeField] private GameObject kalip;        // Inspector'dan prefab atanır
    [SerializeField] private float aralik = 2f;       // saniye
    [SerializeField] private int enFazla = 10;
    [SerializeField] private float yayilma = 3f;      // üretim noktası çevresinde yatay rastgele sapma

    private int uretilen;

    void Start()
    {
        InvokeRepeating(nameof(Uret), 0f, aralik);
    }

    void Uret()
    {
        if (uretilen >= enFazla)
        {
            CancelInvoke(nameof(Uret));
            return;
        }
        Vector3 konum = transform.position + new Vector3(Random.Range(-yayilma, yayilma), 0f, 0f);
        Instantiate(kalip, konum, Quaternion.identity);
        uretilen++;
    }
}

05

Teslim ve tamamlanma ölçütleri

  • Eşya boş bir nesneden bileşen eklenerek kurulmuş (hazır Sprite/3D Object menüsüyle değil).
  • Eşya prefab olarak kaydedilmiş, sahnede en az beş kopyası var.
  • Kalıp değişikliğinin kopyalara yayıldığı ve override'ın bunu nasıl engellediği gösterilebiliyor.
  • Uretici script'i prefab'dan kopya üretiyor.
06

İleri görev

Uretici.cs'ye, her üretilen kopyanın rengini rastgele değiştiren bir satır ekleyin. İpucu: 2B'de GetComponent<SpriteRenderer>().color, 3B'de GetComponent<Renderer>().material.color; rastgele renk için Random.ColorHSV().
