02

Bölüm A · Ses (20 dk)

İlerleme
0 / 4
  1. İçe aktarın

    Dört sesi _Proje/Audio'ya sürükleyin. Kısa efekt oldukları için Load Type: Decompress On Load.

  2. Ses nesnesi

    Yonetim nesnesine Add Component → Audio Source (Play On Awake kapalı) ve SesGeriBildirimi.cs. Dogru Sesi ve Yanlis Sesi alanlarına sesleri sürükleyin.

  3. Seçeneklere bağlayın

    Secenek2D.cs (ya da Secenek3D.cs) içinde SkorYonetici satırının hemen altına şu satırı ekleyin:

    if (SesGeriBildirimi.Ornek != null) SesGeriBildirimi.Ornek.Cal(dogruMu);
    Kontrol: Doğru ve yanlış seçenekler farklı ses çıkarıyor; arka arkaya doğru yapınca ses mekanik tekrar gibi duyulmuyor.
  4. İsteğe bağlı: zıplama sesi

    Oyuncuya ayrı bir Audio Source ekleyip hareket script'inde zıplama anında GetComponent<AudioSource>().Play() çağırın.

SesGeriBildirimi.cs
using UnityEngine;

// Doğru ve yanlış yanıtlar için ses çalar. Sahnede bir tane bulunur;
// Secenek script'leri SesGeriBildirimi.Ornek.Cal(...) ile çağırır.
[RequireComponent(typeof(AudioSource))]
public class SesGeriBildirimi : MonoBehaviour
{
    public static SesGeriBildirimi Ornek { get; private set; }

    [SerializeField] private AudioClip dogruSesi;
    [SerializeField] private AudioClip yanlisSesi;
    [SerializeField, Range(0f, 0.2f)] private float perdeSapmasi = 0.05f;   // ±%5

    private AudioSource kaynak;

    void Awake()
    {
        Ornek = this;
        kaynak = GetComponent<AudioSource>();
    }

    public void Cal(bool dogruMu)
    {
        // Perdeyi hafifçe rastgeleleştir: art arda çalınınca mekanik duyulmaz
        kaynak.pitch = 1f + Random.Range(-perdeSapmasi, perdeSapmasi);
        kaynak.PlayOneShot(dogruMu ? dogruSesi : yanlisSesi);
    }
}

Bölüm B · Kullanıcı testi (40 dk)

Sınıf üçerli gruplara ayrılır; her tur 10 dakika sürer, kişiler dönüşümlü olarak oyuncu ve gözlemci olur. Oyununuzu üç farklı kişiye oynatın. Bölüm C · Web derlemesi (30 dk)

İlerleme
0 / 6
  1. Platform

    File → Build Profiles → Web → Switch Platform. İlk geçiş birkaç dakika sürebilir.

  2. Sahneler

    Scene List'e oyunun sahnesini ekleyin; ilk sırada olsun.

  3. Sıkıştırma

    Player Settings → Publishing Settings: Compression Format Gzip; Decompression Fallback işaretli (GitHub Pages ve itch.io gibi sunucu ayarı değiştirilemeyen yerler için).

  4. Derleyin

    Build; masaüstünde değil, proje dışında boş bir klasör seçin (ör. Derleme_Web).

    Kontrol: Klasörde index.html, Build ve TemplateData var.
  5. Yerelde deneyin

    index.html'ye çift tıklamak çalışmaz. Unity'de Build And Run kullanın ya da klasörde bir terminal açıp şunu çalıştırın, sonra tarayıcıda http://localhost:8000:

    Terminal
    python -m http.server 8000
    Kontrol: Oyun tarayıcıda açılıyor ve oynanıyor.
  6. Paylaşın (isteğe bağlı)

    itch.io'da ücretsiz bir hesap açıp Upload new project → Kind of project: HTML, derleme klasörünün zip'ini yükleyin, This file will be played in the browser'ı işaretleyin. Proje ayarlarında sayfayı Draft ya da Restricted bırakıp bağlantıyı yalnızca sınıfla paylaşabilirsiniz.

05

Teslim ve tamamlanma ölçütleri

  • Doğru ve yanlış yanıtlar farklı seslerle bildiriliyor.
  • Üç gözlem formu doldurulmuş; en az birinde “bu oyun ne öğretiyor?” yanıtı kazanımla karşılaştırılmış.
  • İki düzeltme kararı, dayandığı bulguyla birlikte yazılmış.
  • Web derlemesi yerel sunucuda ya da çevrim içi çalışıyor.
Bu hafta topladığınız bulgular ve düzeltmeler, final ölçütlerindeki kullanıcı testi maddesinin (6 puan) kanıtıdır. Formları saklayın; final raporuna ekleyeceksiniz.
06

Sık karşılaşılan sorunlar

SorunÇözüm
Tarayıcıda “Unable to parse Build/…” ya da boş ekranDecompression Fallback işaretli değil ya da dosyalar file:// ile açılıyor. Yerel sunucu kullanın.
Ses çalmıyorTarayıcılar kullanıcı etkileşimi olmadan ses çalmaya izin vermez; ilk tıklamadan sonra çalışır. Editörde çalışmıyorsa Audio Source'un Mute'u ya da Game penceresinin Mute Audio'su açık olabilir.
Derleme çok büyükKullanılmayan paketleri Package Manager'dan kaldırın; büyük dokuları küçültün.
07

Final projeniz için aynı testi 14. haftadan önce bir kez daha, bu kez hedef kitlenize yakın birileriyle yapmayı deneyin. Final teslimine web derlemesinin bağlantısını ekleyeceksiniz.
