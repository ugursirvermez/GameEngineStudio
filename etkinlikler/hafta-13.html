Bölüm 1

Ses ekleyin

20 dk
İlerleme
0 / 3
  1. İçe aktarın

    Sesleri _Proje/Audio'ya alın; kısa efektler için Load Type Decompress On Load.

  2. Ses nesnesi

    Yonetim'e Audio Source (Play On Awake kapalı) ve SesGeriBildirimi.cs; iki ses alanını doldurun.

  3. Seçeneklere bağlayın

    Secenek script'inizde SkorYonetici satırının hemen altına ekleyin:

    if (SesGeriBildirimi.Ornek != null) SesGeriBildirimi.Ornek.Cal(dogruMu);
    Kontrol: Doğru ve yanlış farklı sesler çıkarıyor; art arda doğrular mekanik duyulmuyor.
SesGeriBildirimi.cs
using UnityEngine;

// Doğru ve yanlış yanıtlar için ses çalar. Sahnede bir tane bulunur;
// Secenek script'leri SesGeriBildirimi.Ornek.Cal(...) ile çağırır.
[RequireComponent(typeof(AudioSource))]
public class SesGeriBildirimi : MonoBehaviour
{
    public static SesGeriBildirimi Ornek { get; private set; }

    [SerializeField] private AudioClip dogruSesi;
    [SerializeField] private AudioClip yanlisSesi;
    [SerializeField, Range(0f, 0.2f)] private float perdeSapmasi = 0.05f;   // ±%5

    private AudioSource kaynak;

    void Awake()
    {
        Ornek = this;
        kaynak = GetComponent<AudioSource>();
    }

    public void Cal(bool dogruMu)
    {
        // Perdeyi hafifçe rastgeleleştir: art arda çalınınca mekanik duyulmaz
        kaynak.pitch = 1f + Random.Range(-perdeSapmasi, perdeSapmasi);
        kaynak.PlayOneShot(dogruMu ? dogruSesi : yanlisSesi);
    }
}

Web'de yayınlayın

30 dk
İlerleme
0 / 5
  1. Platform

    File›Build Profiles›Web›Switch Platform. Sahnenizi Scene List'in başına ekleyin.

  2. Sıkıştırma

    Player Settings›Publishing Settings:

    Compression FormatGzipDecompression Fallbackişaretli
  3. Derleyin

    Build; proje dışında boş bir klasör seçin (ör. Derleme_Web).

    Kontrol: Klasörde index.html, Build ve TemplateData var.
  4. Yerelde deneyin

    index.html'ye çift tıklamak çalışmaz. Unity'de Build And Run ya da klasörde:

    Terminal
    python -m http.server 8000

    sonra http://localhost:8000.

    Kontrol: Oyun tarayıcıda oynanıyor.
  5. Paylaşın

    İsteğe bağlı: itch.io'da Kind of project: HTML ile derleme klasörünün zip'ini yükleyin; sayfayı Restricted bırakıp bağlantıyı yalnızca sınıfla paylaşın.
